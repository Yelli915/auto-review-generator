# Screenshots

포트폴리오 제출 전에 이 디렉터리에 UI 캡처를 추가합니다.

권장 파일명:

- `01-login.png`
- `02-category.png`
- `03-upload-edit.png`
- `04-product-options.png`
- `05-keywords.png`
- `06-review-streaming.png`

캡처 기준:

- 데스크톱 1440px 이상 화면에서 주요 흐름을 캡처합니다.
- 모바일 화면이 중요하면 같은 단계의 모바일 캡처를 `*-mobile.png`로 추가합니다.
- 실제 상품 URL이나 개인정보가 노출되지 않도록 테스트 데이터로 캡처합니다.
